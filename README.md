## 程式用途

本程式用於清理「桌遊體驗」（每人 120.00 元）與「電影欣賞」（每人 80.00 元）兩場活動的原始報名字串（統一大小寫、去除半形空白並切分為串列），再透過集合（`set`）去重與運算，計算各場人數、共同參加者、只參加單場者、全部不重複參加者、通知名單前兩位、報名人次與各場／總應收金額。
